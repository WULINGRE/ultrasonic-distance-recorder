

# STM32 超声波测距与彩屏显示

中文 | [English](README.md)

基于 STM32F103C8T6、CS100A 超声波模块和 ST7735S 彩色液晶屏的嵌入式测距项目。系统通过外部中断与定时器记录回波脉宽，换算距离并以毫米为单位显示，提供连续测量、多次采样滤波和超时提示，可作为嵌入式测距学习及智能门锁检测场景的开发基础。



## 功能

- 使用 EXTI0 检测回波上升沿、下降沿，使用 TIM2 记录回波高电平持续时间。
- 支持单次测量和多次采样计算：采集 10 个距离值，排序后去除两端各 2 个值，对中间 6 个值求平均。
- 使用 32 位中间变量进行距离换算和求和，避免相关计算中的 16 位溢出。
- 通过 SPI1 驱动 ST7735S，支持 RGB565、清屏、区域填充、像素绘制和字符放大。
- 支持 8×16 ASCII 字符及字库内的 16×16 中文字形，提供 UTF-8 字符串显示接口。
- 上电显示红、白色测试画面；主循环更新距离，初始测量超时时显示红色 `---`。

## 硬件与接线

需要 STM32F103C8T6 开发板、CS100A 超声波模块、ST7735S 彩屏，以及适配开发板的 SWD 下载器。面板为 128×160 像素规格，当前代码使用 **160×128 的逻辑坐标范围**。电源电压与信号电平应按实际模块规格确认，所有模块共地。

| 模块 | 信号 | STM32 引脚 | 用途 |
| --- | --- | --- | --- |
| CS100A | TRIG | PB0 | 触发测量，当前脉冲宽度为 50 μs |
| CS100A | ECHO | PA0 | 回波输入，连接 EXTI0 |
| ST7735S | SCK / SCL | PA5 | SPI1 时钟 |
| ST7735S | SDA / MOSI | PA7 | SPI1 数据输出 |
| ST7735S | CS | PB12 | 低电平选中 |
| ST7735S | DC / A0 | PB13 | 命令、数据选择 |
| ST7735S | RST / RES | PB14 | 低电平复位 |
| ST7735S | BL / LED | PB10 | 背光，默认高电平使能 |
| 各模块 | GND | GND | 共地 |

PA6 被驱动配置为输入，但不需要连接屏幕 MISO；当前代码不读取屏幕状态。屏幕逻辑尺寸、扫描方向、偏移和背光极性在 `Hardware/st7735.h` 中配置。

## 编译与运行

1. 使用 Keil µVision 打开根目录的 `tem_mis_disp.uvprojx`。
2. 工程目标为 `STM32F103C8`，记录的编译器为 ARM Compiler 5.06 update 5；设备包为 `Keil.STM32F1xx_DFP.2.2.0`。根据本机安装情况配置工具链和设备支持。
3. 保持工程宏 `USE_STDPERIPH_DRIVER`、`STM32F10X_MD`，头文件目录已包含 `Start`、`Library`、`System`、`Hardware`、`User`。
4. 确认开发板时钟与 `Start/system_stm32f10x.c` 的配置一致。当前选择 72 MHz 系统时钟；TIM2 使用 `72 - 1` 分频，按 72 MHz 定时器时钟得到 1 μs 计数周期。
5. 执行 Build，按实际下载器配置 SWD 接口并下载固件。编译产物位于 `Objects/`，不纳入版本控制。
6. 上电后观察红、白色画面及欢迎文字，将目标物放在传感器前，检查距离值是否更新。

主循环每轮显示完成后延时 300 ms；总刷新周期还包含测量、采样间隔和显示时间，并非固定 300 ms。

## 测量流程

发出触发脉冲 → 等待回波上升沿 → 清零 TIM2 → 回波下降沿读取计数 → 换算距离 → 更新显示。

当前换算公式为：

```text
distance_mm = echo_time_us × 343 / 2000
```

TIM2 自动重装载值为 `0xFFFF`。在 1 MHz 计数频率下，等待上升沿或测量高电平期间的定时器溢出会触发超时，单个计数窗口约为 65.536 ms。显示单位为毫米，不代表经过标定的毫米级测量精度。

| 接口 | 作用 |
| --- | --- |
| `cs100a_init()` | 初始化 GPIO、EXTI0 和 TIM2 |
| `cs100a_start()` | 启动一次测量；忙时忽略重复请求 |
| `cs100a_isFinished()` / `cs100a_isTimeout()` | 查询结束及超时状态 |
| `cs100a_getDistanceMm()` | 读取一次已完成测量的距离 |
| `cs100a_CalDistanceMm()` | 阻塞采集 10 个距离值并返回截尾平均值 |

## 主机测试与字体预览

LCD 主机测试需要 Windows、MSVC x64 工具链、64 位 Python 和 PowerShell。脚本使用 Python `ctypes` 加载测试 DLL；将下面的占位路径替换为本机包含 `bin`、`include` 等目录的 MSVC 版本目录：

```powershell
.\tests\run_lcd_tests.ps1 -MsvcRoot "<本机 MSVC 版本目录>"
```

测试输出写入 `Objects/lcd_tests/`。最近一次检查中，代码能够编译和链接，但 LCD 坐标断言失败：测试按 128×160 的终点检查，而当前驱动尺寸为 160×128。修改作者标注前的版本也在同一断言失败，当前不能将测试状态标记为通过。参见[检查记录](docs/仓库上传前敏感信息检查.md)。

安装 Pillow 后，可在仓库根目录生成字体预览：

```powershell
python .\_analysis\render_font.py
```

## 当前限制

- 主循环和多次采样函数采用阻塞等待；扩展其他实时任务时需要调整调度方式。
- 多次采样中的超时结果会作为 `0` 进入排序，当前没有独立剔除无效样本。
- 中文显示只支持已有字库中的字形；新增汉字需要补充字体数据。
- 不同 ST7735S 模组可能需要调整扫描方向、偏移或初始化参数。
- 本次文档整理未进行实物烧录或测距标定。

显示初始化与排查细节见 [LCD 显示故障排查与修改说明](docs/LCD显示故障排查与修改说明.md)。
